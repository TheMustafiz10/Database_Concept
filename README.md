# Database Concept (DBMS)


Welcome to the **Database Concepts** repository! This repository contains notes, explanations, examples, and important topics related to Database Management Systems (DBMS).

The main goal of this repository is to build a strong understanding of database fundamentals, relational database concepts, and database design.

---

## Objectives

- Understand fundamental database concepts.
- Learn Database Management Systems (DBMS).
- Understand relational database design.
- Learn database normalization techniques.
- Explore SQL queries and database operations.
- Understand primary keys, foreign keys, and relationships.
- Develop knowledge of database security and integrity.

---

## Topics Covered

| No. | Topic | Description |
|---|---|---|
| 01 | Introduction to DBMS | Basic database concepts and definitions |
| 02 | Database Models | Hierarchical, Network, and Relational Models |
| 03 | ER Diagram | Entity Relationship Diagram |
| 04 | Relational Model | Tables, Rows, Columns, and Relationships |
| 05 | Keys in DBMS | Primary Key, Foreign Key, Candidate Key, etc. |
| 06 | Database Normalization | 1NF, 2NF, 3NF, BCNF, 4NF, and 5NF |
| 07 | SQL | Structured Query Language |
| 08 | SQL Commands | DDL, DML, DQL, DCL, and TCL |
| 09 | Database Relationships | One-to-One, One-to-Many, and Many-to-Many |
| 10 | Database Constraints | NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, etc. |
| 11 | Database Transactions | ACID Properties |
| 12 | Database Security | Authentication, Authorization, and Access Control |
